# Demo recordings

Each tape records one `kube-noob demo` scenario with [VHS](https://github.com/charmbracelet/vhs). The release
workflow renders every tape from the released wheel and attaches the GIFs to the GitHub release, so recordings always
match the shipped version. The demos are offline and use a throwaway data directory.

```bash
vhs demos/diagnose.tape
```

## Videos

All three are rendered in 4K from real output, with the kube-noob brand music; the walkthrough is also narrated
(needs Node with Playwright and Chromium, ffmpeg, and python3 with `numpy` and `kokoro-onnx`):

| Video | Command | Source |
|---|---|---|
| 2-minute walkthrough + YouTube thumbnail | `demos/video/render.sh <out-dir>` | `kube-noob demo` and `selftest` |
| kube-noob as tools for Claude (MCP), 70 s | `demos/video/render.sh <out-dir> mcp <session.jsonl>` | a `claude -p --plugin-dir plugin/kube-noob --output-format stream-json --verbose` session, with its prompt in `<session>.prompt.txt` |
| kube-noob as a sidecar on a cluster | `demos/video/render.sh <out-dir> sidecar <transcript.txt>` | the transcript `scripts/demo_sidecar_kind.sh` records in CI (job `e2e-kind`, OpenShift 4.22 leg) |

The voice-over, title options and chapters are in [youtube-walkthrough.md](youtube-walkthrough.md). Prompts for an
AI-generated teaser, sidecar and MCP explainer are in [ai-video-prompts.md](ai-video-prompts.md).

### Animated videos, no video model

The same three scripts, rendered locally in the look of the Grok teaser (navy server room, glass terminal, rocket
mascot) with a Kokoro voice-over and the kube-noob brand music. Every terminal line in them is copied from a real run:
the 0.2.2 CLI, the CI sidecar transcript and the recorded Claude session.

| Video | Length | Command |
|---|---|---|
| Teaser: no AI inside | 30 s | `demos/video/stage/build.sh <out-dir> teaser` |
| kube-noob as a sidecar | 56 s | `demos/video/stage/build.sh <out-dir> sidecar` |
| kube-noob as tools for Claude (MCP) | 57 s | `demos/video/stage/build.sh <out-dir> mcp` |
| Compliance regimes: FedRAMP, EU AI Act, GDPR | 71 s | `python3 demos/video/stage/compliance.py <out-dir>` then `node demos/video/stage/capture.js <out-dir>` |

Needs python3 with `numpy` and `kokoro-onnx` (`pip install kokoro-onnx numpy`), Node with Playwright and Chromium,
and ffmpeg. Scenes, captions and voice-over lines are in [video/stage/videos.json](video/stage/videos.json).

The compliance video's script is in its own file, [video/stage/compliance.json](video/stage/compliance.json), because
every claim in it names a NIST SP 800-53 control id and `videos.json` may type no digits. It runs through the same
schema, voice, music, caption and loudness path; `compliance.py` is the `voiceover.py` step for it. Each claim traces
to a file in the repository: FedRAMP wording and the control ids to [docs/compliance.md](../docs/compliance.md),
read-only and never-reads-Secrets to [docs/safety-contract.md](../docs/safety-contract.md), the DNS-only chart
NetworkPolicy to [SECURITY.md](../SECURITY.md), and no accounts / no telemetry / on your machine only to
[PRIVACY.md](../PRIVACY.md). The scene before the end card carries the disclaimer; `compliance.py` refuses a script
without it.

### Voice and music

- **Voice:** [Kokoro-82M](https://github.com/thewh1teagle/kokoro-onnx) (Apache-2.0), voice `af_heart`, run locally.
  The first run downloads the model from GitHub and checks its sha256. Pick another voice with `--voice` (`af_bella`,
  `am_michael`, `bm_george`, ...) or `KN_VOICE` for `render.sh`; `--engine piper` brings back the earlier Piper voice.
- **Music:** generated by [video/audio_kit.py](video/audio_kit.py): an upbeat business groove in C major at 104 bpm
  built on the kube-noob motif (C, G, high C), which also plays on every end card. No samples, no licences.
- **Music level:** `--music-db` (or `KN_MUSIC_DB` for `render.sh`) sets the music against the voice: `-12` by
  default, `-18` quieter, `-6` louder, `off` for none. Every render keeps `voice.wav` and `music.wav`, so the level
  can change later without rendering the picture again:

```bash
python3 demos/video/audio_kit.py remix <out-dir>/teaser --music-db -18 --video <out-dir>/teaser/kube-noob-teaser.mp4
```
