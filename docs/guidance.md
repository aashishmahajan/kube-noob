# Guidance traceability

Every product rule is listed here with the automated checks that enforce it. `tests/test_guidance.py` fails if a
referenced test or CI step disappears, so a rule cannot lose its check without this table changing in the same review.

Reference formats: `tests/<file>.py::<test>` for a pytest test, and `ci:<step or job name>` for a GitHub Actions step
or job.
